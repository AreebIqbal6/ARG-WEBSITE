# ARG REGISTRARS PAKISTAN

Official web application for **ARG REGISTRARS PAKISTAN** (`argregistrars.com`).

ARG REGISTRARS PAKISTAN provides accredited ISO management certifications (ISO 9001, ISO 14001, ISO 45001), C-TPAT supply chain security audits, technical factory evaluations, and international registrar solutions.

## Technology Stack
* **Framework:** Next.js 16 (App Router)
* **Library:** React 19
* **Styling:** Tailwind CSS v4 & Glassmorphism
* **Animations:** Framer Motion, Lenis Smooth Scrolling
* **Icons:** Lucide React

## Getting Started
First, install the dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
