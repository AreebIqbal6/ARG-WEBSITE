# ARG-WEBSITE Autonomous Progress Log
Date: 2026-11-23

## Problem Statement
User reported that on mobile phone (Android Chrome), the entire site did not load properly (blank/ghost areas below header).
Investigation revealed that 50+ elements across home and subpage components were configured with Framer Motion `initial={{ opacity: 0 }}`. When Next.js server-side renders or pre-renders static HTML, it outputs `style="opacity: 0; transform: translateY(...)"`. On mobile devices with latency, delayed hydration, or failed intersection observer callbacks due to negative margins (`margin: "-5%"`), elements remained 100% invisible. Furthermore, Lenis smooth scrolling was adding an unnecessary wrapper around the DOM.

## Plan
1. MOB-01: Remove Lenis SmoothScrolling wrapper from RootLayout.
2. MOB-02: Eliminate `initial={{ opacity: 0 }}` and negative viewport margins from all home components.
3. MOB-03: Eliminate `initial={{ opacity: 0 }}` from subpages (Services, Audits, About, 404).
4. MOB-04: Run next build to ensure zero compilation or type errors.
5. MOB-05: Push to origin/main, verify live mobile deployment on www.argregistrars.com with Playwright.
